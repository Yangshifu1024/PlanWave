# 提案：列表页显示效果优化（分隔线 / 子任务树 / 时间分组 / 已完成分区）

- 日期：2026-09-14
- 状态：accepted
- 分支：`feature/task-list-visual-refresh`
- 任务：`docs/tasks/feat-task-list-visual-refresh/plan.md`

## 背景

任务列表当前没有行间分隔，仅靠 `space-y-0.5`（2px）与圆角卡片区分，任务一多就糊成一片；
子任务只用「每行一段左边框（`ml-9 border-l pl-2.5`）」示意层级，被圆角与行间距切碎，读不出父子关系；
已完成任务只是排到列表末尾并加删除线，没有分区或折叠，长列表被历史任务稀释；
列表页勾选完成还会弹确认框（`TaskRow.tsx` 的 `requestConfirm`），高频操作被中断。

## 竞品调研结论（摘）

| 产品 | 关键做法 | 可借鉴点 |
|---|---|---|
| Material Design 3 | 相关行用 **inset divider**（对齐内容、非通栏）；分区用通栏分隔；强调「线条过密即噪音」 | 行间用内嵌发丝线；分区用带标签的整宽分隔 |
| Things 3 | 项目内用 **Heading 当分区标题**；任务行底部极细发丝线；克制 | 分区标题 + 细线；父/子层级 |
| Todoist | 支持多级子任务；**已完成任务折叠到分区底部**，由 Display→Completed 切换 | 可折叠「已完成」分区 |
| TickTick | Folder→List→Section→Task→Subtask；父任务行有展开箭头；支持按时间分组 | 父任务 chevron；按截止时间分组 |
| Microsoft To Do | 极简，「步骤」= 子任务，行间细分隔 | 轻量分隔 |
| 分隔线通识 | 负空间优先；用线时内嵌、低对比、勿滥用 | 统一一条 1px 线，对齐内容 |

## 需求（本迭代）

1. 任务之间增加**内嵌发丝分隔线**（从勾选框右侧起，对齐内容），悬停/选中行时隐藏，使高亮行呈悬浮胶囊感。
2. 子任务改为**连续竖向引导线 + 缩进 + 更小的浅色文字**，替换现有逐行断开的左边框。
3. 非回收站视图按截止时间**分组**：逾期 / 今天 / 明天 / 7 天内 / 以后 / 无日期，分组标题带数量。
4. 已完成任务折叠进**「已完成 (N)」分区**（默认折叠，偏好持久化）；搜索时退化为平铺列表。
5. 列表页勾选完成**去除确认弹框**，改为即时勾选 + Toast「撤销」。

## 方案要点（决策）

- **分隔线**：`TaskRow` 用 `before:` 伪元素绘制 1px 内嵌线（`left-11 right-3`，对齐文字起始列），
  `group-hover`/选中态 `opacity-0`；仅顶层存活任务显示，子任务/墓碑不显示。
- **子任务树**：引导线画在父任务下方的**子任务容器**上（连续覆盖整段），每个子任务补一小段水平肘线；
  子任务行 `ml-9`、标题 `text-[13px] text-zinc-500`；`TaskRow` 不再承担边框。
- **分组**：在 `visibleTree`（子任务树）之上对**顶层节点**分组，父任务的桶决定其子任务归属；
  父不可见被提升的孤儿子任务按自身截止时间入桶。空分组不渲染。搜索时不做分组、不做已完成分区。
- **已完成分区**：`splitCompleted` 按顶层节点 `completed` 拆分；仅 `all`/项目视图会出现
  （today/upcoming 的筛选本就排除已完成）；偏好存 `localStorage`（`planwave.ui.showCompleted`）。
- **即时勾选 + 撤销**：新增 `actions.toggleTaskWithUndo(id)`，内部调用现有 `toggleTask` 并发
  HeroUI Toast（`Toast.Provider` 挂载于 `App.tsx`），Toast 内置「撤销」按钮回滚。详情面板的确认逻辑保持不动，控制改动面。

## 验收标准

- [ ] 顶层任务之间出现 1px 内嵌分隔线；悬停或选中该行时分隔线消失。
- [ ] 子任务有连续竖向引导线 + 缩进，父/子文字层级明显；引导线无断裂。
- [ ] 非回收站视图按时间分组并显示分组标题与数量；`today` 仅「逾期/今天」，`upcoming` 为「今天/明天/7 天内」。
- [ ] `all`/项目视图出现可折叠「已完成 (N)」分区，默认折叠，展开/折叠偏好重启后保留。
- [ ] 搜索时列表平铺（无分组、无已完成分区），结果正确。
- [ ] 列表页勾选即时生效并弹出带「撤销」的 Toast；撤销回滚完成状态。
- [ ] 回收站视图行为不变（平铺、多选、批删、清空）。
- [ ] `pnpm lint` / `pnpm typecheck` / `pnpm test:web` / `pnpm build:web` / `pnpm test:e2e` 全绿。
