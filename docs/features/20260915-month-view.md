# 提案：月视图（全部 + 各项目）

- 日期：2026-09-15
- 状态：accepted
- 分支：`feature/month-view`
- 任务：`docs/tasks/feat-month-view/plan.md`

## 背景

任务只有「截止时间」（`due_date`）一个时间字段，列表页按时间分桶（逾期/今天/明天/7 天内/以后/无日期）
已经能回答「接下来要做什么」，但回答不了「这个月的事怎么分布」「哪天被塞爆了」「下周空不空」。
当前没有任何视图切换机制，也没有日历组件。

## 需求（本迭代）

1. 在**「全部」和每个项目视图**内提供「列表 / 月」呈现切换器；`今天`/`最近 7 天`/`回收站` 不提供月视图。
2. 月视图为**日历月网格**：7 列、**周一起始**、固定 6 行（含上下月补位日，淡化但仍可点击/拖入）。
3. 每个日期格展示**当天到期的顶层任务**（最多 3 条），超出显示「+N」；今天高亮、逾期红字、重复任务带图标。
4. **点击空格子新建**：打开既有 `QuickAddModal` 并预填该日期；项目视图归属该项目，「全部」归属收集箱。
5. **点击任务条目**：打开既有 `TaskDetail` 侧栏；格内可直接勾选完成。
6. **桌面拖拽改期**：拖动任务条目到另一天 → 改 `due_date`（保留原时刻），松手后 Toast 可撤销。
7. **「未排期」抽屉**（桌面）：列出当前视图下无 `due_date` 的顶层任务，可拖入网格排期，也可把任务拖回抽屉以清除日期。
8. **移动端降级**：保持 7 列，格内只显示圆点/计数，点某天打开当天任务浮层；移动端不做拖拽（改期走详情面板）。
9. **搜索联动**：月视图下输入关键词自动切回列表视图；切回月视图时清空搜索。
10. **模式持久化**：呈现模式记在 `localStorage`（`planwave.ui.viewMode`），`全部` 与项目视图共享。
11. **键盘**：格子与条目可聚焦，格子 Enter 新建；v1 不做方向键网格导航。

## 方案要点（决策）

- **范围**：仅 `{kind:"smart",smart:"all"}` 与 `{kind:"project"}` 支持月视图；其余视图忽略 `viewMode` 强制列表。
- **收录规则**：网格只显示**顶层任务**（子任务不单独占格）；无 `due_date` 的任务不进网格（进「未排期」抽屉）；
  逾期任务只落在它自己那一天，不钉到今天；已完成任务是否显示跟随列表页已有偏好 `planwave.ui.showCompleted`。
- **周一起始 + 固定 6 行**：月份切换时网格高度稳定，补位日可跨月拖入。
- **自绘网格**：不引入日历库，复用 `lib/dates.ts` 与 Tailwind。HeroUI 的 `Calendar` 虽支持日格子自定义内容，
  但其 cell 尺寸与变体样式不适配「溢出 + 拖拽命中区 + 移动端圆点」这三项需求。
- **拖拽自实现**：Pointer Events，按下位移 > 4px 判定为拖拽，否则视为点击；不引第三方 dnd 库。
- **当天任务浮层**：同一个 `DayTasksOverlay` 组件，桌面 `placement="center"`、移动端 `placement="bottom"`，
  复用 `TaskRow` 渲染条目，内含「添加任务到这天」（移动端唯一的建任务入口）。
- **改期语义**：移到某天保留原时刻；原本无日期（从抽屉拖入）→ 该天 `00:00`；拖回抽屉 → `due_date: null`。

## 非目标（本迭代不做）

- 跨月拖拽（拖到网格边缘自动翻月）：先翻月再拖。
- 多选拖拽。
- 移动端拖拽。
- ARIA grid 方向键导航。
- 任务开始日期 / 持续时长（数据模型没有该字段）。

- [ ] 月网格周一起始、固定 6 行；上下月补位日淡化；今天高亮。

- [ ] 点击任务条目打开详情；格内勾选完成即时生效并弹「撤销」Toast。
