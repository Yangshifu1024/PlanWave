# 修改：精简工具行输入框的提示文案

- 日期：2026-09-16
- 分支：`fix/search-placeholder`

## 背景

任务列表顶部工具行有两个输入框，提示文案偏长，窄屏（手机）上会被截断；且其中一处按视图切换文案，信息量与收益不成比例。

| 输入框 | 原文案 | 现文案 |
|---|---|---|
| 搜索（`TaskList.tsx:186`） | `搜索任务、备注、标签…` | `搜索` |
| 新建任务（`TaskList.tsx:221-226`） | 按视图切换：`添加到「收集箱」（无项目）` / `添加任务，回车填写详情` | `输入任务` |

## 理由

- 搜索框原文案在罗列匹配字段（标题/备注/标签），但这一点由搜索结果本身就能体现；窄屏截断后反而只剩残缺的半句。
- 新建任务框原文案的前半句在说明任务落点（收集箱/当前项目），而落点由当前视图与列表本身表达；后半句在说明回车快捷方式，属于首次使用即可发现的交互。改为固定文案后同时消除了视图分支，代码更简单。
- 两者都不影响功能、`data-testid` 与测试断言（测试未断言这两处文案）。
